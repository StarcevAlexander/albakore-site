КАК ПОЧИНИТЬ ОТПРАВКУ ЗАЯВОК С САЙТА (ошибка почты Mail.ru)
============================================================


ЧТО СЛУЧИЛОСЬ
-------------

Форма «Получить консультацию» на сайте промсервис33.ру перестала отправлять заявки.

Причина: почта Mail.ru больше не разрешает сторонним сервисам (в нашем случае —
EmailJS, который рассылает заявки с сайта) входить в ящик по обычному паролю.
Теперь для этого нужен специальный «пароль приложения» — отдельный пароль,
который создаётся в настройках Mail.ru именно для таких сервисов.

Чинится за 10–15 минут, ничего в сайте менять не нужно. Нужно сделать два шага:

  1. Создать «пароль приложения» в Mail.ru.
  2. Вписать этот пароль в настройки EmailJS.


ШАГ 1. СОЗДАТЬ «ПАРОЛЬ ПРИЛОЖЕНИЯ» В MAIL.RU
--------------------------------------------

Понадобится доступ к тому ящику Mail.ru, с которого отправляются заявки с сайта
(тот ящик, который указан в EmailJS в сервисе отправки).

1. Откройте в браузере почту: https://mail.ru и войдите в ящик.

2. Нажмите на свою аватарку (кружок с фото/буквой) в правом верхнем углу
   и выберите «Пароль и безопасность».
   Либо просто откройте ссылку: https://id.mail.ru/security

3. Найдите раздел «Пароли для внешних приложений» и откройте его.

4. Если Mail.ru попросит сначала включить двухфакторную аутентификацию
   (подтверждение входа по СМС) — включите её, следуя подсказкам на экране.
   Без неё пароли приложений создать нельзя.

5. Нажмите «Добавить» (создать новый пароль приложения).

6. В качестве названия впишите что-нибудь понятное, например: EmailJS сайт

7. Если спросят тип приложения — выберите «Почтовая программа» / SMTP.

8. Mail.ru покажет сгенерированный пароль (набор букв и цифр, примерно 16 символов).

   !!! ВАЖНО: этот пароль показывается ТОЛЬКО ОДИН РАЗ. Сразу скопируйте его
   (выделить → Ctrl+C) и временно вставьте в заметки. Если потеряли — не страшно,
   просто удалите его и создайте новый.

Официальная справка Mail.ru на эту тему:
https://help.mail.ru/mail/security/protection/external


ШАГ 2. ВПИСАТЬ ПАРОЛЬ В EMAILJS
-------------------------------

1. Откройте сайт https://dashboard.emailjs.com и войдите в аккаунт EmailJS
   (тот, на котором настроена отправка с сайта).

2. В меню слева выберите «Email Services».

3. Найдите в списке сервис с ID service_wq3ndk7 (сервис Mail.ru) и нажмите на него.

4. Откроются настройки подключения к почте. Найдите поле Password (пароль).

5. Сотрите старый пароль и вставьте пароль приложения из Шага 1 (Ctrl+V).
   Логин (адрес ящика) оставьте как есть.

6. Нажмите кнопку сохранения — «Update Service» (или «Save»).

7. Если рядом есть кнопка «Test» / «Send test email» — нажмите её.
   Должно прийти тестовое письмо на ящик. Пришло — значит всё получилось.


ШАГ 3. ПРОВЕРИТЬ ФОРМУ НА САЙТЕ
-------------------------------

1. Откройте сайт https://promservis33.ru

2. Заполните форму «Получить консультацию» (можно вписать своё имя и телефон)
   и отправьте.

3. Проверьте почту — должно прийти письмо
   «Новая заявка с сайта промсервис33.ру».

Письмо пришло — готово, форма снова работает.


ЕСЛИ НЕ ПОЛУЧИЛОСЬ
------------------

* Mail.ru не даёт создать пароль приложения
  → Сначала включите двухфакторную аутентификацию (Шаг 1, пункт 4).

* Пароль приложения потеряли, не успели скопировать
  → Удалите его в том же разделе и создайте новый.

* Тест в EmailJS всё равно выдаёт ошибку
  → Проверьте, что логин в EmailJS — это полный адрес ящика
    (например, example@mail.ru), а пароль — именно пароль приложения,
    без пробелов в начале и в конце.

* Письма не приходят, хотя тест прошёл
  → Загляните в папку «Спам» в ящике.

* Ничего не помогает
  → Сообщите разработчику текст ошибки (можно скриншотом).


СПРАВОЧНАЯ ИНФОРМАЦИЯ (для разработчика)
----------------------------------------

- Ошибка, с которой всё началось: 412 Precondition Failed от api.emailjs.com,
  внутри — ответ Mail.ru: 535 5.7.0 NEOBHODIM parol prilozheniya /
  Application password is REQUIRED.
- EmailJS: service ID service_wq3ndk7, template ID template_nq6y6al.
- Шаблон письма описан в файле EMAILJS_TEMPLATE.md.
- Код сайта менять не требуется — проблема только в способе авторизации
  EmailJS в ящике Mail.ru.
